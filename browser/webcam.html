Primate Intelligence — webcam streaming

Server-side, create a stream and a client token (never put secret keys in a page): 

STREAM=$(curl -s -X POST https://api.primateintelligence.ai/v1/streams \
  -H "Authorization: Bearer ***" -H "Content-Type: application/json" \
  -d '{"prompt": "can you see a person?"}')
TOKEN=$(curl -s -X POST https://api.primateintelligence.ai/v1/client_tokens \
  -H "Authorization: Bearer ***" -H "Content-Type: application/json" \
  -d "{\"scopes\":[\"streams:signal\"],\"stream_id\":$(echo $STREAM | jq .id),\"ttl_s\":600}" | jq -r .token)
